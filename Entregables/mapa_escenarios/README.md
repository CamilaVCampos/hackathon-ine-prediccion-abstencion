# Mapa de escenarios con y sin intervención

| Archivo | Contenido |
|---|---|
| `mapa_escenarios_2027.geojson` | Polígonos municipales (Marco Geoestadístico 2025 de INEGI, simplificados a 500 m) con el pronóstico, el semáforo y los escenarios de 1 a 5 puntos. Se abre en QGIS, ArcGIS, Tableau o Power BI |
| `diccionario_mapa_2027.csv` | Descripción de cada columna del GeoJSON |

Tablero interactivo en Tableau Public: <https://public.tableau.com/views/RiesgodeAbstencin2027/Dashboard1>

Los polígonos sirven para visualizar, no para medir áreas. San Juan Mixtepec y San Pedro Mixtepec (Oaxaca) comparten dato (`AGRUPADO = Sí`) y Villa de Pozos (San Luis Potosí) aparece sin dato (`EN_BASE = No`).
