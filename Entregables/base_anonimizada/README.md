# Base anonimizada

Base de datos empleada en el análisis. Son conteos agregados por grupo (municipio, sexo, rango de edad y tipo de sección); no contiene datos personales ni permite identificar a ninguna persona.

| Archivo | Contenido |
|---|---|
| `base_limpia.zip` | `base_limpia.csv`: 540,024 filas con la abstención de 2009 a 2024 por grupo (descomprimir para usar) |
| `diccionario_base_limpia.txt` | Descripción de las columnas de `base_limpia.csv` |
| `escenarios_2027.csv` | Una fila por municipio (2,475): pronóstico 2027, semáforo y escenarios con intervención de 1 a 5 puntos |
| `diccionario_escenarios_2027.txt` | Descripción de las columnas de `escenarios_2027.csv` y de `pronostico_2027.csv` |
